### 2. Lectura del Riesgo (Guía general)
Si ya tienes el porcentaje, aquí tienes cómo evaluar el riesgo:
| Porcentaje Usado | Nivel de Riesgo | Lectura y Acción |
| :--- | :--- | :--- |
| **0% - 70%** | **Bajo** ✅ | Todo está normal. Tienes espacio suficiente 
para actualizaciones y archivos temporales. |
| **71% - 85%** | **Moderado** ⚠️ | Empieza a ser momento de hacer limpieza
limpieza. Algunos sistemas empiezan a reducir la eficiencia del caché. |
| **86% - 95%** | **Alto** 🚨 | **Riesgo real.** Las actualizaciones del si
sistema podrían fallar y el rendimiento puede degradarse (especialmente en 
SSDs que necesitan espacio libre para el *wear leveling*). |
| **96% - 100%** | **Crítico** 💀 | **Peligro inminente.** El sistema puede
puede volverse inestable, las aplicaciones pueden cerrarse inesperadamente 
("crash") y podrías tener problemas para iniciar sesión (especialmente en L
Linux, donde el disco lleno impide cargar el entorno gráfico). |
**Si estás en el nivel "Alto" o "Crítico", te recomiendo:**
1. Vaciar la papelera de reciclaje.
2. Borrar archivos temporales (`/tmp` en Linux o `%TEMP%` en Windows).
3. Revisar carpetas de descargas o logs antiguos.
4. Desinstalar aplicaciones que no uses.
