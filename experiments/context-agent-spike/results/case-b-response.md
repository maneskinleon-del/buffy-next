## Respuesta del Agente

No puedo diagnosticar el equipo en este momento porque no me has proporcionado ninguna información sobre él.

Para poder ayudarte a diagnosticarlo, por favor indícame o comparte:

1. **Sistema operativo y versión** (por ejemplo, Linux, Windows, macOS, Android).
2. **Especificaciones de hardware principales** (CPU, memoria RAM, almacenamiento disponible, GPU si aplica).
3. **El problema o síntoma específico** (lentitud, errores, bloqueos, servicios que no arrancan).
4. **Logs, salida de terminal o reporte de diagnóstico** (por ejemplo, ejecutando un comando de diagnóstico o reporte de estado del sistema como `buffy doctor --context`).
